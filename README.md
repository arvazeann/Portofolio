## Stack

Untuk repository baru, stack yang direkomendasikan:
- Next.js App Router
- React
- TypeScript
- Tailwind CSS

Gunakan stack repository saat ini bila sudah ada dan layak. Hindari menambah backend atau database tanpa kebutuhan yang jelas.

## Menjalankan proyek

Perintah final tergantung konfigurasi repository. Untuk proyek Next.js yang memakai npm, pola umumnya:

```bash
npm install
npm run dev
```

Lalu buka `http://localhost:3000`.

Periksa `package.json` untuk perintah `lint`, `typecheck`, `test`, dan `build` yang benar-benar tersedia. Jangan menganggap semua script tersedia.
